# Sales and Profit Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing sales, profit, marketing,
inventory, COGS, budget and product information using SQL.

The objective is to use SQL queries to answer business-related
questions and generate meaningful insights from the dataset.

## 🗂️ Dataset

The project contains three main tables:

### FactTable
Contains sales and financial information such as:

- Date
- ProductID
- Profit
- Sales
- Margin
- COGS
- Total Expenses
- Marketing
- Inventory
- Budget Profit
- Budget COGS
- Budget Margin
- Budget Sales
- Area Code

### ProductTable

Contains:

- Product Type
- Product
- ProductID
- Type

### LocationTable

Contains:

- Area Code
- State
- Market
- Market Size

## 🎯 Objectives

The project answers questions related to:

- State-wise analysis
