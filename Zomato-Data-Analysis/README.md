🍽️ Zomato Data Analysis

📌 Project Overview

This project focuses on analyzing Zomato restaurant data using Microsoft SQL Server. The project demonstrates practical SQL concepts such as User-Defined Functions, 
Stored Procedures, Transactions, Views, Triggers, Window Functions, CASE statements, Aggregate Functions, ROLLUP, and WHILE loops.

The objective is to perform different data analysis operations on restaurant information and practice advanced SQL programming concepts.

📂 Dataset

The project uses a Zomato restaurant dataset containing information such as:

1. OrderId
2. RestaurantName
3. RestaurantType
4. Rating
5. No.of.Rating
6. AverageCost
7. OnlineOrder
8. TableBooking
9. CuisinesType
10. Area
11. LocalAddress
12. Delivery time

▶️ How to Run

1. Open SQL Server Management Studio (SSMS).
2. Create the database:
CREATE DATABASE ZOMATO;
3. Select the database:
USE ZOMATO;
4. Import or load the Zomato dataset into the ZOMATO table.
5. Execute the SQL queries in the .sql file.
6. Run each section to observe the results.
